# DP-800 Lab 02

## Implementación de objetos de programabilidad con SQL

**Autor:** Carlos Picón  
**Curso:** DP-800-lab-2
**Fecha:** 22/09/2026

En este laboratorio trabajé con la base de datos de ejemplo **AdventureWorksLT** para crear y probar distintos objetos de programabilidad de SQL Server.

## Contenido del laboratorio

- Conexión y comprobación de la base de datos AdventureWorksLT.
- Creación y validación de una vista.
- Creación y ejecución de un procedimiento almacenado.
- Creación y uso de una función escalar.
- Creación y consulta de una función con valores de tabla en línea (TVF).
- Creación y prueba de un trigger para registrar cambios.

- SQL Server 2019 o superior, o Azure SQL Database.
- Base de datos de ejemplo AdventureWorksLT.
- Una herramienta para ejecutar consultas T-SQL, como SQL Server Management Studio o Azure Data Studio.
